# FXTradingSystem

A new Python FX trading application built around OpenAgentFabric (OAF).

This repository selectively migrates capabilities from [FXMarket](https://github.com/costab06/FXMarket), [FXAgents](https://github.com/costab06/FXAgents), and [forex_stat_arb](https://github.com/costab06/forex_stat_arb), without changing the source repositories.

## Planned development

1. Create a minimal installable application and tests.
2. Migrate FX market data and quantitative strategy components.
3. Port statistical arbitrage from R to Python.
4. Integrate OAF workflows and selected FXAgents analysis.
5. Add backtesting, risk controls, paper execution, and reconciliation.

Agents must not directly submit broker orders.
